# 平ドラ・RobStride中継基板

このブランチは、PCから受け取った車体速度を3輪分に変換し、RobStride 05へ操舵角、平ドラへ駆動rpmを送ります。

## PC → 送信基板

FDCAN1は公開版の `tourobo2026_ws` と同じ標準ID `0x100`、CAN FD＋BRS、12バイトを受け取ります。各値はビッグエンディアンのfloat32です。

| バイト | 内容 |
| --- | --- |
| 0–3 | `vx` [m/s] |
| 4–7 | `vy` [m/s] |
| 8–11 | `omega` [rad/s] |

送信基板は従来の軸変換 `(vy, -vx, omega)` を適用します。車輪の配置と半径から、3輪それぞれの操舵角とN5065軸のrpmを計算します。

## 送信基板 → モーター

FDCAN3でRobStrideへ拡張IDのClassic CANを送り、平ドラへは標準ID `0x301`、`0x302`、`0x303` のClassic CANを送ります。平ドラのデータは8バイトで、先頭4バイトがリトルエンディアンのfloat32 rpm、byte 4がPID方式、byte 5が制御方式です。

操舵角は実機の原点と操舵比を適用し、車輪側±90°に収まる向きを選びます。180°反対の向きを選んだ場合は駆動rpmを反転します。駆動速度は平ドラの許容範囲である±2000 rpmに収めます。原点復帰が終わり、全輪の角度が新しく、操舵誤差が10°以内になってから駆動指令を送ります。上位指令が300 ms途切れた場合や操舵角が60 ms以上古い場合は、送信可能な下流へ0 rpmを送ります。

## コードの入口

- `main.c` はCubeMXの初期化の後、`swerve_start()` と `swerve_poll()` を呼びます。
- `drive_can.c` はPCからの受信検証と平ドラへの送信です。
- `swerve.c` は実機設定、独ステの座標変換と操舵目標の選択、20 ms周期の送信、シリアル診断です。
- `swerve_homing.c` は原点センサーを使って3輪を順に原点復帰します。
- `robostride_can.c` は操舵の送受信、角度返信の管理、IDスキャンとBus-Off診断です。
