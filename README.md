# 平ドラ・RobStride中継基板

このブランチは、PCの3輪指令をRobStride 05の操舵角と平ドラの駆動rpmに中継します。

## PC → 送信基板

FDCAN1は標準ID `0x110`、CAN FD＋BRS、24バイトを受け取ります。各値はビッグエンディアンのfloat32です。

| バイト | 車輪 | 内容 |
| --- | --- | --- |
| 0–7 | 右前 | 操舵角 [rad]、N5065軸速度 [rpm] |
| 8–15 | 左前 | 操舵角 [rad]、N5065軸速度 [rpm] |
| 16–23 | 後ろ | 操舵角 [rad]、N5065軸速度 [rpm] |

原点合わせで決まる直進方向を0 radとし、左回りを正とします。指令角は±π、許容rpmは±2000です。車体の並進・旋回から各輪の指令を作る計算はPCで行います。従来の車体速度フレーム（`0x100`）は受信対象外です。

## 送信基板 → モーター

FDCAN3でRobStrideへ拡張IDのClassic CANを送り、平ドラへは標準ID `0x301`、`0x302`、`0x303` のClassic CANを送ります。平ドラのデータは8バイトで、先頭4バイトがリトルエンディアンのfloat32 rpm、byte 4がPID方式、byte 5が制御方式です。

操舵角は実機の原点と操舵比を適用し、車輪側±90°に収まる向きを選びます。180°回避した場合は駆動rpmを反転します。原点復帰が終わり、全輪の角度が新しく、操舵誤差が10°以内になってから駆動指令を送ります。上位指令が300 ms途切れた場合や操舵角が60 ms以上古い場合は、送信可能な下流へ0 rpmを送ります。

## コードの入口

- `main.c` はCubeMXの初期化の後、`swerve_start()` と `swerve_poll()` を呼びます。
- `drive_can.c` はPCからの受信検証と平ドラへの送信です。
- `swerve.c` は実機設定、操舵目標の選択、20 ms周期の送信、シリアル診断です。
- `swerve_homing.c` は原点センサーを使って3輪を順に原点復帰します。
- `robostride_can.c` は操舵の送受信、角度返信の管理、IDスキャンとBus-Off診断です。
